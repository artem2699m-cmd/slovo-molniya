# ⚡ Слово-молния

Простая браузерная игра на скорость печати. Слова падают сверху вниз — набирай их, пока они не упали на землю.

## Как запустить

Скачай проект и открой файл `index.html` в любом браузере. Установка и интернет не нужны.

## Как играть

1. Нажми «Играть».
2. Печатай падающие слова в поле внизу. Совпавшие с началом слова буквы подсвечиваются.
3. Слово засчитывается, как только ты набрал его целиком.
4. Если слово упало на землю, теряешь жизнь. Всего их три.
5. Чем больше счёт, тем быстрее падают слова и чаще появляются новые.

Лучший результат («Рекорд») сохраняется в браузере.

## Технологии

Один файл `index.html`: HTML, CSS и JavaScript без библиотек.
